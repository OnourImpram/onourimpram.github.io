Laboratorium inventaris katalog

Ekspor katalog terbitan, verifikasi integritas berkas, dan hitung ulang jenis sumber dengan kode yang sama.

Draf metode dan pembelajaran. Telaah ilmiah dan penelaahan penutur asli belum selesai. Tidak memberikan akreditasi atau izin praktik.

Ikat data dan keluaran ke satu versi

Latihan mengekspor ID, judul asli, jenis, tahun, URL, dan cakupan telaah sebelumnya ke CSV. Satu baris adalah sumber, bukan peserta. SHA256 mengidentifikasi berkas. Python memeriksa checksum dan ID unik sebelum menghitung jenis.

Hitung ulang hasil yang ditampilkan

Tabel dihitung dari katalog saat build. Skrip Python menghitung ulang secara independen dan membandingkannya dengan manifes memakai pustaka standar. Notebook opsional memuat kode yang sama. Berkas Quarto dikonfigurasi menjalankan skrip tersebut.

Batasi penafsiran

Jumlah sumber bukan ukuran efektivitas intervensi atau besar bidang. Tidak ada di katalog bukan berarti tidak ada penelitian. Laboratorium awal ini mengajarkan integritas metadata dan komputasi yang dapat diulang. Tidak memuat data peserta, efek klinis, atau meta-analisis lengkap.

Ruang kerja sains terbuka

Keluaran hanya menggambarkan katalog pilihan MARSAM. Bukan bibliografi lengkap, data klinis, atau peta bukti sistematis. Tanggal penelaahan sumber sebelumnya dipertahankan.

"""Reproduce the selected catalogue inventory. No participant data or network calls.
Python 3.10 or later. Standard library only. Keep catalogue.csv and
lab-manifest.json beside this file, or in the notebook working directory.
"""
from pathlib import Path
from collections import Counter
import csv
import hashlib
import io
import json

def analyze(directory: Path) -> dict:
    manifest = json.loads((directory / 'lab-manifest.json').read_text(encoding='utf-8'))
    raw = (directory / 'catalogue.csv').read_bytes()
    if hashlib.sha256(raw).hexdigest() != manifest['dataSHA256']:
        raise ValueError('Catalogue checksum mismatch. Restore the original data and matching manifest.')
    rows = list(csv.DictReader(io.StringIO(raw.decode('utf-8-sig'))))
    ids = [row['source_id'] for row in rows]
    if len(ids) != len(set(ids)) or any(not item for item in ids):
        raise ValueError('Source identifiers must be non-empty and unique.')
    counts = dict(sorted(Counter(row['kind'] for row in rows).items()))
    result = {'records': len(rows), 'by_type': counts}
    if result != manifest['expectedResult']:
        raise ValueError('Computed result does not match the release manifest.')
    return result

if __name__ == '__main__':
    directory = Path(__file__).resolve().parent if '__file__' in globals() else Path.cwd()
    try:
        result = analyze(directory)
        print(json.dumps(result, ensure_ascii=False, indent=2))
    except (OSError, ValueError, KeyError) as exc:
        raise SystemExit(f'Catalogue check failed. {exc}') from exc
