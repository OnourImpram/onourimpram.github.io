# V9 yüzey dokusu

Üç yüzey haritası, konuşmada üretilmiş zarif_ceviz_masa_köşesi.png görselinin yazısız ahşap ayrıntısından türetilmiştir. Bu malzeme görünümüdür. Gerçek atölye fotoğrafı, gerçek ağaç türü doğrulaması veya yeni ürün fotoğrafı değildir. Küçük doku yaması yansıtılarak tekrarlanmış ve üç tonla yorumlanmıştır. Kaynak çözünürlüğünden daha fazla ayrıntı üretildiği iddia edilmez.
