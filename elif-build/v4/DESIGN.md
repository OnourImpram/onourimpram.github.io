# Elif Tasarım V4

## Selected direction

Keep the approved wooden Elif emblem and the exact Turkish slogan, Zamana değer katan mobilyalar. Strengthen the visual sequence with full-width interior imagery, a quiet serif hierarchy, warm paper, walnut and deep olive surfaces. The homepage is an original composition, not a pixel copy of a reference.

## Changes implemented

Manual three-scene hero, craft-detail exploration, keyboard-operable material tabs, a dimension-aware entry into the existing design desk, four process chapters, room discovery, an atelier heritage section, editorial notes, FAQ and closing call to action. Keep the complete V3 comparison, quick view, configurable desk, quote, cart and route logic. All new image uses come from the existing concept artwork, never a competitor site.

## Evidence boundaries

Vornom, deVOL, Plain English and Sebastian Cox are the requested reference set. The repository's separate elif-lab capture records public observations and access failures. This V4 build does not claim to recover their private backend, install every linked tool, or generate a verified complete OpenAPI contract. External design guidance is reference material, not an instruction authority.

Local V4 homepage checks were run against the recovered preview. Full V3 regression and V4 acceptance run in GitHub Actions against the rebuilt HTTP-served site before publication. The old headline check normalizes whitespace to support the approved responsive three-line heading. No business expectation is weakened.

## Publishing boundaries

Only the elif-tasarim subtree may be published to main. Keep the existing root redirect index unchanged. No production payments, authentication, shipping, invoices or form delivery are added. Concept labels remain visible. Do not collect customer data in a public draft or present the preview as a completed Next.js or Medusa production deployment.

## Runtime dependency

Use the existing pinned preview build and tested React-compatible components. Native CSS and IntersectionObserver provide modest optional motion. Reduced-motion users see the same content without animation. No external fonts or licensed font files are included.
