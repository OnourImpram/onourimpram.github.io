# Onour Impram Portfolio (retired)

This showcase page has been retired. The canonical personal site is
**https://onourimpram.com**, and the open-source work now lives at
https://onourimpram.com/en/open-source (Turkish: /tr/acik-kaynak).

`index.html` is kept as a redirect rather than deleted: GitHub does not allow
a user Pages site to be deactivated, so removing the file would leave a 404
instead of a forward. The previous content remains in this repository's git
history.

The per-project documentation sites under this domain are served from their own
repositories and are unaffected:
`/mneme/`, `/mergen/`, `/routeledger/`, `/vocation-os/`,
`/claude-code-for-social-scientists/`.
